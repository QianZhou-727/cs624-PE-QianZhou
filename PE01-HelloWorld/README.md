# Input

This Hello World mobile app uses three pieces of information: my name, my degree program, and my school. These values are written directly in the code, so the user does not need to enter anything. The app uses React Native to display this information.

# Process

The application is created using React Native and Expo. It uses one View component to hold three Text components. Each Text component displays one piece of information. The StyleSheet is used to set the background color to yellow and place the text in the center of the screen. When the app starts, React Native reads the code and displays the information using the styles.

# Output

The final output is a simple mobile screen with a yellow background. My name, degree program, and school are displayed in three separate lines in the center. This exercise helps me understand how React Native components and styles work together.
