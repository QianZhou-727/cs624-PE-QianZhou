# cs624-pe-Qian

# Input

The application uses a predefined user profile containing a name, occupation, profile description, and avatar image. The profile information is written directly in the React Native source code. No external data or user input is required to display the profile card.

# Process

The application uses React Native components such as View, Text, and Image to construct a profile card. StyleSheet.create() defines the styles for the card and its contents. The View component organizes the layout, while the Text component displays the user's name, occupation, and description. Styling properties such as fontSize, fontWeight, textAlign, marginTop, and lineHeight improve readability and appearance. The avatar is displayed inside a circular container, and the card uses a blue background with rounded corners and a black border.

# Output

The application displays a centered blue profile card containing a circular avatar, the user's name, occupation, and description. The final interface is tested using Expo Go on an iPhone. A screenshot is saved as evidence of the completed application.
